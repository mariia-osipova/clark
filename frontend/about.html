Cómo lo construimos

Tecnología real, decisiones deliberadas.

Cada decisión técnica tuvo un motivo concreto. Sin sobre-ingeniería, sin atajos que rompan en producción.

LangGraph + OpenAI

El agente corre sobre un grafo de estado con LangGraph. Cada nodo tiene una responsabilidad clara: buscar, clarificar, armar el carrito o responder al usuario.

Búsqueda semántica local

Embeddings con sentence-transformers sobre el catálogo de Carrefour Argentina. Encuentra el producto correcto aunque el cliente no use el nombre exacto del SKU.

Vanilla frontend, Python stdlib backend

Sin frameworks pesados. HTML, CSS y JS puro en el frontend. Python con stdlib y SQLite en el backend. Rápido, liviano, fácil de entender y de integrar.
